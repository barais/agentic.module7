### MODULE 7 — Agents pour la recherche
> Usage concret #2, thème porteur.

1. **Agents de recherche bibliographique** — synthèse de littérature, deep research (ex. agents de recherche profonde)
2. **Agents pour l'analyse de données** — exploration, nettoyage, visualisation, statistiques
3. **Découverte scientifique assistée** — virtual labs, AI co-scientist, protocoles de recherche (ex. agents de James Zou à Stanford)
4. **Agents pour les sciences de la vie et la chimie** — laboratoires autonomes, génération d'hypothèses
5. **Agents pour la reproductibilité** — protocoles, pipelines de calcul, documentation des expériences
6. **Écriture et relecture d'articles** — aide à l'écriture, revue de papier, vérification d'arguments
7. **Limites épistémiques** — ce qu'un agent ne peut pas valider, nécessité de l'expert humain
